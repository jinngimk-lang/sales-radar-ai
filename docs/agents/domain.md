# Domain Documentation Layout

Layout: single-context.

Read order for engineering work:

1. `CONTEXT.md`
2. `.agent/SKILL_REGISTRY.md`
3. Relevant `.agent/*.md` product and data-model documents
4. Relevant `docs/adr/*.md`
5. The originating issue/spec and current implementation

Create ADRs under `docs/adr/` for decisions that change provider priority, source/evidence semantics, privacy boundaries, browser execution, workspace ownership, or public interfaces.
