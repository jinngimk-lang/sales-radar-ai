# Issue Tracker

Provider: GitHub Issues  
Repository: `jinngimk-lang/sales-radar-ai`

Use issues for durable bugs, specifications, and follow-up work. Implementation uses an isolated branch and pull request. The PR description must reference the originating issue or design document and list the red/green verification commands.

Pull requests are not automatically treated as external requirements; the user request, issue, screenshots, and accepted design remain the specification sources.
